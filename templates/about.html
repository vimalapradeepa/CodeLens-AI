About CodeLens AI

AI-Powered Multi-Agent Open Source Project Analyzer

Project Overview

CodeLens AI is a final-year AI & Data Science project that demonstrates a Multi-Agent AI system for automated software comprehension of open-source GitHub repositories.

The system accepts multiple GitHub URLs, filters them by keyword relevance, ranks them, and then dispatches two independent custom agents to deeply analyse repository structure, extract code entities, build a semantic code graph, and answer developer questions through Retrieval-Augmented Generation.

Phase 1 — Repository Analysis Agent

  • GitHub URL validation (5–10 repos)
  • Keyword-based relevance scoring with configurable weights
  • Top-10 repository ranking
  • Shallow repository cloning via Git
  • Python AST-based code entity extraction (classes, methods, functions, imports, calls)
  • Java source analysis using javalang + regex fallback
  • Repository statistics computation
  • Structured JSON knowledge generation
  • Human-readable Markdown report

Phase 2 — Semantic Code Graph Agent + RAG

  • Semantic code graph built from Agent 1 knowledge (NetworkX + PyVis)
  • Node types: Repository, File, Class, Method, Function, Module, Package
  • Edge types: CONTAINS, IMPORTS, CALLS, INHERITS, DEFINES, DEPENDS_ON
  • Architecture layer inference (Presentation / Service / Data)
  • Entry-point and key-component detection
  • Cyclic dependency detection
  • Interactive HTML graph visualisation
  • Shared Knowledge layer consumed by RAG
  • RAG pipeline: chunking → sentence-transformer embeddings → FAISS store → LLM
  • Developer Q&A with source-file references

Technology Stack

Code Analysis Python AST, javalang
Graph NetworkX, PyVis
RAG sentence-transformers, FAISS
